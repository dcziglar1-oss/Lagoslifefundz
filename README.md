# Lagos Life TopUp Hub

This repo contains a public storefront and admin dashboard for Lagos Life balance top-ups.

## Files
- `index.html` — public storefront
- `admin.html` — admin dashboard

## GitHub Pages
To publish the site:
1. Open the repository in GitHub.
2. Go to Settings -> Pages.
3. Choose Branch: `gh-pages` and folder `/ (root)`.
4. Save.

The site will be live at:
https://dcziglar1-oss.github.io/lagos-life-topup/
